# Tell Index

Perfume answers from [Tell Index](https://tellindex.com): how a perfume smells and how it comes
across to the people around you, where it works (office, dates, seasons), store prices and
samples — and, with a Tell Index account, your own perfume wardrobe.

## What's inside

- **Connector** — the Tell Index MCP server, `https://mcp.tellindex.com/mcp`.
- **Skill `tellindex`** — how to read Tell Index data and answer perfume questions.

## Install

- **Claude Code:** `/plugin marketplace add tellindex/tellindex-plugin`, then
  `/plugin install tellindex@tellindex`.
- **Claude (web, desktop, Cowork):** Customize → Plugins → add the marketplace `tellindex/tellindex-plugin`.

## Account

Search, perfume profiles and prices work without an account. Your wardrobe and price alerts ask
you to sign in to Tell Index the first time you use them; you can disconnect Claude at any time in
your Tell Index settings.

## Your data

The plugin sends Tell Index only what a request needs: perfume names, your language and market,
and the wardrobe changes you ask for. It does not read your chat history or Claude's memory.
Privacy policy: https://tellindex.com/en/privacy · Terms: https://tellindex.com/en/terms
